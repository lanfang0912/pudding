# AI Rules for This Project

## Before You Start
1. Read this file before making any changes.
2. Review the existing codebase.
3. Keep changes focused and minimal.

## Git Workflow
After each working milestone:
1. git add .
2. git commit -m "<clear description>"
3. git push origin main

Do not wait until the entire project is finished before pushing.

## Development Principles
- Do not modify unrelated files.
- Preserve the existing architecture.
- Prefer small, incremental changes.
- Keep the site deployable at all times.

## If Interrupted
If the session ends unexpectedly:
1. Pull the latest changes from GitHub.
2. Review recent commits.
3. Continue from the unfinished task.

## Safety Rules
- Do not delete files unless necessary.
- Do not remove existing functionality without explicit instruction.
- Ask before making destructive changes.

## Documentation
Update README.md if major features are added.

## Default Instruction
Always commit and push after completing any functional milestone.
